Digital Public Infrastructure (DPI) Principles

Land data is published through open REST APIs with standardized GeoJSON geometry. Third-party institutions like credit rating agencies, crop insurance aggregators, and satellite monitoring systems can query parcel boundaries, ownership validation, and crop records with zero friction.

GET /api/parcels/ Try Live API
Cadastral Parcels GeoJSON FeatureCollection

Returns all digitized cadastral polygons with embedded ownership, crop, and status attributes in standard WGS84 GeoJSON format.

Supported Query Parameters:
ParameterTypeDescription
qstringFull-text search across Khasra number, ULPIN, or Owner name
villagestringFilter by village name (e.g. Rampur Khurd)
land_usestringFilter by land use type (e.g. Irrigated Agri)
statusstringFilter by title legality (Clear, Disputed, Under Mutation)
