How Verification Works

BhuRaksha uses a 3-step cryptographic process to confirm record authenticity

1
Enter ULPIN

Type the 14-character Unique Land Parcel Identification Number (e.g. PB-KPT-2024-1001) or scan from a printed RoR certificate QR code.

2
Hash Recalculated

The system recalculates the SHA-256 fingerprint of the parcel's boundary coordinates, area, and ownership data in real time.

3
Result Displayed

If the stored and computed hashes match → ✅ Genuine. If they differ → ❌ Tamper Alert. No match means the record was modified.

What is a ULPIN?

ULPIN (Unique Land Parcel Identification Number) is a 14-character permanent digital ID assigned to every cadastral land parcel in India. Format: ST-DST-YYYY-NNNN

ST = State Code DST = District YYYY = Year NNNN = Serial
Example ULPIN
PB-KPT-2024-1001
Punjab · Kapurthala · 2024 · Plot 1001
✅
Genuine Record

SHA-256 hash stored at registration matches the hash recomputed now. The parcel data — boundary, area, owner — has never been tampered with since registration.

❌
Tamper Alert

The recomputed hash does not match the stored fingerprint. This means the parcel's area, boundary coordinates, or ownership data was changed after registration.
